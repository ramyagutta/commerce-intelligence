# AI Commerce Intelligence

An AI platform for e-commerce support teams. It classifies customer tickets,
retrieves the right company policy, drafts cited replies for human approval,
and detects emerging problems, such as many customers complaining about
the same seller.

**Status:** Work in progress (started November 2026)

## Important note about the data

- Order, seller and delivery data come from the public
  [Olist Brazilian E-Commerce dataset](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce).
- **The support tickets in this project are synthetic.** They are generated
  and linked to real Olist orders, with known issues injected on purpose so
  the issue-detection system can be validated.
- The dataset is not included in this repository. See "Setup" below.
